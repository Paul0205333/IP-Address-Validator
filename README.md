## How to Run

1. Clone the repository:
```bash
git clone https://github.com/your-username/your-repository.git
````

2. Open the project folder:
```bash
cd your-repository
```

3. Install Flask:
```bash
pip install flask
```

4. Run the application:
```bash
python main.py
```

5. Open your web browser and go to:
```text
http://127.0.0.1:5000
```
